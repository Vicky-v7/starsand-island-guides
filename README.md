# Starsand Island Guides

Unofficial fan guide site for Starsand Island (Seed Sparkle Lab, v1.0 released 2026-08-18).
An SEO practice project for the 生财有术「AI 产品（出海-热词游戏站）」voyage.

- Live: https://starsand.vickyv7.com
- Stack: static HTML generated by `build.py` (Python) from `src/layout.html` + `src/content/*.html` + `src/pages.json`
- 12 pages: home + guides index + 10 guide pages, sitemap.xml, robots.txt, GA4, self-hosted analytics beacon
- Research corpus in `research/` (keyword selection, page matrix, per-page sources — facts only, TBC-marked where unverified)

Built with Claude Code. Not affiliated with the developer or publisher.
